绿色便携截图工具（ShotPortable）
================================

一、目标
- Win10 及以上 x64，免安装 Python / Docker / 其它运行时
- 打开即用：默认离线本机（OCR + 中英翻译模型随包）
- 可在编辑器勾选「本次使用联网翻译」；下次启动仍恢复离线

二、功能
1. 托盘常驻，热键 Ctrl+Alt+A 框选截图
2. 标注：矩形/椭圆/箭头/画笔/文字/马赛克
3. 保存 / 复制图片
4. 离线 OCR 提取文字（RapidOCR）
5. 离线对照翻译（Argos en↔zh），结果在右侧栏，可划选复制
6. 启动后后台预加载翻译模型：
   - 托盘提示「正在加载 / 已就绪」
   - 编辑器右侧栏显示加载进度
   - 模型未就绪时点「对照翻译」会等待加载完成后自动开始

三、开发运行
  py -3.11 -m venv .venv
  .\.venv\Scripts\pip install -r requirements.txt
  .\.venv\Scripts\python.exe scripts\download_models.py
  .\.venv\Scripts\python.exe run.py
  （或双击 启动开发版.bat）

四、绿色发布
  .\scripts\build_portable.ps1
  输出：dist\ShotPortable-Green\
  把整个文件夹拷贝到目标电脑，运行 ShotPortable.exe

  正确目录结构（精简后约 1GB 内）：
    ShotPortable.exe
    使用说明.txt
    models\argos_installed\...   （运行时只需已安装模型）
    _internal\...                （不含 torch/spacy）

  构建脚本会自动剔除：torch、spacy、stanza、argos 原包/缓存等无用文件。

五、离线翻译与排障
- OCR 模型：随 rapidocr-onnxruntime 打包
- 翻译模型（发布包）：models\argos_installed\
- 开发机下载源：models\argos\*.argosmodel（不必随绿色包分发）
- 联网翻译依赖外网，仅在勾选后启用
- 若对照翻译很慢或卡住：
  1) 确认 models\argos_installed 与 exe 同级且含 en↔zh
  2) 等待托盘/右侧栏显示「模型已就绪」再翻译
  3) 重新运行 scripts\build_portable.ps1 生成带热补丁的绿色包
- 若提示缺少模型：在开发机运行 download_models.py 后重新打包，
  或把 models\argos_installed 复制到 exe 旁
